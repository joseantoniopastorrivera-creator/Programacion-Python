# Programación en Python - 1º DAM

Repositorio dedicado a las prácticas, ejercicios, Unidades de Trabajo (UT) y proyectos desarrollados en el lenguaje Python dentro del módulo de Programación de 1º de DAM (Desarrollo de Aplicaciones Multiplataforma).

## 📁 Estructura del Repositorio

El contenido se organiza de manera modular por unidades y bloques de aprendizaje oficiales:

* **`UT01-Introduccion-A-Python-Y-Tipos-De-Datos/`**: Sintaxis básica, variables, tipos de datos primitivos, operadores aritméticos, entrada/salida por teclado (`input`/`print`), manipulación avanzada de cadenas (*strings*, *slicing*, métodos) y ejercicios prácticos de examen.
* **`UT02-Estructuras-Condicionales/`**: Estructuras de control de flujo condicionales (`if`, `elif`, `else`) para la toma de decisiones lógicas.
* **`UT03-Colecciones-Y-Estructuras-De-Datos/`**: Teoría, guías de estudio y proyectos prácticos sobre colecciones en Python (Listas, Tuplas, Sets y Diccionarios), algoritmos de conteo, flujos de datos y proyectos como *Fake News Detector*, *Social Media Analytics* y recomendadores.
* **`UT04-Programacion-Orientada-A-Objetos-Y-Modulos/`**: Programación Orientada a Objetos (POO), definición de clases, constructores, atributos, métodos, módulos, paquetes y proyectos empaquetados (`proyecto_biblioteca`, `proyecto_tienda`, etc.).
* **`UT05-Operaciones-De-Entrada-Y-Salida/`**: Gestión y procesamiento de operaciones de entrada y salida de datos.
* **`UT06-Bases-De-Datos-Y-Sqlite/`**: Conexión a bases de datos relacionales mediante SQLite, creación de tablas, inserciones avanzadas con `executemany`, consultas parametrizadas, gestión de errores de integridad y operaciones CRUD completas.
* **`Examenes-Y-Simulacros/`**: Casos prácticos integrales y exámenes prácticos de evaluación correspondientes a las diferentes evaluaciones del curso.
